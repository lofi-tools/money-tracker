# Provider marks

Static, audited brand assets used to identify source providers/software. No scripts, event handlers, external resources or runtime downloads.

- Nexo uses the existing bundled NEXO mark and its recorded CC0 provenance.
- Binance: Simple Icons 16.0.0, https://cdn.jsdelivr.net/npm/simple-icons@16.0.0/icons/binance.svg (CC0-1.0); palette set to Binance yellow.
- MetaMask: official logo pack linked from https://metamask.io/assets; https://assets.ctfassets.net/clixtyxoaeas/1d7h0Cnm1RaQ0TspxaTS0H/57418d60d3a13fbee748be1ca560235a/MetaMask-Logo-Pack__4_.zip, `MetaMask/MetaMask-icon-fox.svg`. Original geometry and palette retained; Illustrator styles flattened to static fills.
- Kraken: Kraken Financial logo sourced from https://www.kraken.com/press/kraken-images, mirrored at https://commons.wikimedia.org/wiki/File:K-logo-wikipedia.svg (PD-textlogo). The castle mark is cropped from the original logotype; static fill retains original purple.

Fetched 14 October 2026. Brand marks remain their owners' identifiers; these assets do not imply a relationship with the provider. Solana uses the same pinned CC0 Cryptocurrency Icons source/version as the other coin marks.
