## Workspace and distribution

The root pnpm workspace explicitly contains `libs/web-design-system` (`@money-tracker/design-system`) and `demos/design-system-showcase`. The showcase consumes `workspace:*`, public TSX exports and the generated stylesheet without its own Panda configuration. Future Solid/Tauri/site consumers use the same boundary. Rust membership remains explicit and independent; stage 5 changes no Rust code, schemas, migrations or provider behavior.

Pinned tools/dependencies: Node 24.21.0 (`.node-version`), pnpm 11.27.0, TypeScript 7.0.2, SolidJS 1.9.17, Panda dev/base preset 2.2.0, Ark Solid 5.39.3, Vite 8.3.4, Solid Vite plugin 2.11.14, and locally bundled `@fontsource-variable/manrope` 5.3.0. The committed `pnpm-lock.yaml` resolves transitive dependencies. pnpm's build allowlist permits only the named watcher/esbuild dependencies; it does not enable all dependency scripts.

Public package exports are `.` (components and presentation types), `./formatting` (pure helpers/types), `./styles.css`, and `./fonts.css`. Sources remain TypeScript/TSX, transpiled by a Solid-aware ES2022 consumer; this is not a compiled universal JS distribution or a published package. `pnpm codegen` regenerates ignored `styled-system` runtime helpers; `pnpm build` also emits ignored `dist/styles.css` and builds the consumer. `prepack` regenerates the package assets. Generated helpers/dependencies/builds/reports are excluded from Git; fresh generation is required before consuming the source package.

Panda 2 uses its explicit base preset for utilities/conditions, with this package's own tokens/recipes. [The stylesheet distribution pattern](https://panda-css.com/docs/design-systems/consume-without-panda) provides complete CSS to consumers: `staticCss.recipes: '*'` emits supported variants even when the example does not use them. `mt-` classes and `--mt-*` variables avoid unprefixed package styles. No application imports private generated paths. A consumer needing its own Panda preset can add a documented integration later; it is not needed for the first app.

## Component and ownership contract

| Exports | Responsibilities |
| --- | --- |
| `ThemeRoot`, `PrivacyProvider`, `usePrivacy` | Controlled system/light/dark theme and normal/hidden/scaled display context. Follow system preference changes; host owns persisted preferences. |
| `Button`, `IconButton`, `PinButton`, `TextField`, `SearchField` | Semantic native controls, labels, disabled/error/focus styles; preserve native button/input attributes where exposed. |
| `GroupingTabs` | Controlled labelled Ark tabs with keyboard navigation and panels. Host supplies items, selection and content. |
| `InlineEdit` | Ark editable with exact text, host validation, labelled input/actions, valid commit, cancel and optional independent pin. Invalid drafts remain editable; no DB/rate mutation or financial calculation. |
| `Money`, `Quantity`, `Rate`, `MoneyFigure`, `SummaryValue` | Exact display formatting and distinct known/partial/unknown/not-applicable states. Rates stay visible in privacy modes. |
| `NavigationEntry`, `AllocationTable` | Selected navigation and semantic caption/headers/rows. Name opens details; a separate labelled arrow expands. Host supplies sorted, visible rows/depth; tables do not calculate totals or infer hierarchy. |
| `DetailsPanel` | Controlled nonmodal right panel within the theme root. Keep the table accessible; focus the close control on opening and restore the supplied triggering element on closing/Escape. Hosts reserve space on wide windows and may overlay at narrow widths. |
| `Badge`, `WarningButton`, `StateMessage`, `Icon` | Neutral/accent/warning/danger cues, labelled warning actions and empty/loading/offline/error presentation. Icons are decorative; button names remain accessible. |

Warm charcoal surfaces, pale sage accents, a matching light palette and separate warning/danger colors use shared semantic tokens. Rows balance compact density with padding; tabular numeric text aligns values. Light/dark tokens, visible keyboard focus and reduced-motion transitions are included. Theme persistence and application settings remain host responsibilities; no system preference or portfolio data is written by these components.

Ark supplies headless [tabs](https://ark-ui.com/docs/components/tabs), editable and dialog interaction. The nonmodal panel explicitly manages focus because it does not trap focus or make the table inert. Its content mounts under `ThemeRoot`, preserving theme variables without a body portal. Hosts provide `returnFocus` for the external name/warning trigger. Inline-edit validation does not overwrite invalid data or apply edits on blur; application validation/pinning/audit remain in Rust/services. Demo Undo is only a callback-driven presentation of host-owned state.

## Exact formatting and privacy

[Formatting helpers](../../libs/web-design-system/src/formatting/index.ts) accept plain decimal strings or the stage-4 rational shape (`numerator`/positive `denominator` integer strings). BigInt display arithmetic never passes financial quantities/quotes/rates through JavaScript numbers. Numeric JSON-like inputs, exponents, malformed values, invalid scales and nonpositive denominators are rejected. `Intl` supplies currency/grouping/minor-unit metadata; it formats the rounded integer part as BigInt, not a narrowed financial number.

USD uses two decimals below absolute $100, whole dollars at $100 or more, no automatic abbreviations and thousands separators. Select precision before rounding: $99.999 becomes $100.00, while $100.25 becomes $100. Display rounding is symmetric half-up. Nonzero values below a minor unit remain distinguishable: $0.004 → <$0.01, −$0.004 → −<$0.01, actual zero → $0.00. Foreign ISO currencies use their currency symbol/minor units (JPY zero, KWD three); no guessed FX conversion occurs. Locale defaults to en-US; application currency/locale support remains host work.

Quantity formatting takes integer-string units and protected scale 0–255, trims only trailing zeros and retains the full exact nonzero decimal, including arbitrarily small balances. Details can use the same helper. Rates render a rounded percentage from an exact fraction and retain tiny nonzero signs as <0.01% rather than zero. These helpers are display operations, not yield/valuation/reconciliation services.

Privacy is `{mode:'normal'|'hidden'|'scaled', scale?:string}`. Hidden values render a mask with safe “Amount hidden”/“Quantity hidden” accessible labels and no raw title/data attributes. Scaled mode defaults to 0.1 and accepts an exact positive factor below 1; scale first, then choose display precision. The same factor applies to money, quantities, debt and earnings; percentages remain unchanged. Neither sorting, actual tracking, dust thresholds nor stored data is changed.

Construct financial JSX under `PrivacyProvider`, including cells created in arrays/memos. The showcase mounts a child component under the provider so preconstructed JSX cannot accidentally capture the normal fallback. Components sanitize their own numeric text; hosts must also sanitize arbitrary child text, custom labels/attributes and editors containing sensitive amounts. Scaled/hidden presentation is not encryption or access control, and it does not remove data from the runtime.
